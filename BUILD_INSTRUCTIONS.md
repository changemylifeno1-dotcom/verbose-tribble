# ROHIT ONE — Android APK Build Guide (100% Free)

### Option A: Build with Gradle on PC / Laptop
1. Open this folder in Android Studio.
2. In the terminal, run:
   ```bash
   ./gradlew assembleRelease
   ```
3. Your compiled APK will be in:
   `app/build/outputs/apk/release/app-release.apk`

### Option B: Build 100% Free via GitHub Cloud (No PC needed)
1. Upload this project to a free GitHub repository.
2. Go to the "Actions" tab.
3. Click "Build ROHIT ONE Release APK" and press "Run workflow".
4. Within 2-3 minutes, download your signed `ROHIT-ONE.apk` directly to your phone!
